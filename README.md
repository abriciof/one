# ONE! 🃏

**ONE!** é uma implementação em Java do clássico jogo de cartas Uno, projetada para ser executada inteiramente no terminal (console). O projeto foca na lógica de jogo, gerenciamento de turnos e interação simples via texto.

## ✨ Funcionalidades

- **Partidas no Console:** Jogue diretamente do seu terminal.
- **Regras Clássicas:** Implementação das mecânicas de cores, números e cartas especiais.
- **Interface Minimalista:** Feedback visual simples para facilitar a jogabilidade.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 11 ou superior)
- **Paradigma:** Programação Orientada a Objetos (POO)

## 🚀 Como Executar

### Pré-requisitos
Certifique-se de ter o JDK instalado e configurado no seu sistema.

### Compilação
Para compilar o projeto e gerar os arquivos na pasta `out`, execute:

```bash
javac -d out -sourcepath src src/com/one/app/Main.java
```

### Execução
Após compilar, inicie o jogo com o comando:

```
java -cp out com.one.app.Main
```

## 📂 Estrutura do Projeto
src/: Contém todo o código-fonte em Java.

out/: Diretório onde os arquivos compilados são armazenados.

com.one.app.Main: Ponto de entrada da aplicação.
